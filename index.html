LAIKA Studio Analytics

LAIKA Studio Analytics is a local workspace for the creator behind Laika Tells. It links published videos to production topics and records their performance so the creator can plan future videos.

The TikTok connection uses Login Kit to identify the authorized creator account. With the creator’s permission, the Display API reads that account’s public videos and their view, like, comment and share counts.
